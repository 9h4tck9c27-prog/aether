# æther social data

This branch is the memory of æther's Instagram robot. It is not deployed.

- `plans/<monday>.json`: each week's posts, written by the creative director on Sunday morning (see `tools/social/BRIEF.md` on main)
- `media/<monday>.json`: links to the rendered images and videos
- `log/posted.json`: what went out, with Instagram links
- `analytics/<monday>.json`: each week's numbers; `analytics/latest.json` is the most recent
- Add a file named `PAUSE` here to stop posting; delete it to resume.
